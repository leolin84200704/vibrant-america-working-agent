# VP-18782 - Work Loop Record

## Ticket Analysis

### [2026-10-12 23:00Z]
- Ticket created by me during VP-18480 Phase A (Dev To Do, P2, assignee Leo). Source: `src/app.module.ts` `LoggerModule.forRoot` -> `pinoHttp.serializers.req(req) { req.body = req.raw.body; return req; }`. pino-http 8.3.3 / pino-std-serializers 6.2.1: the serializer receives the std-serialized request (`id, method, url, query, params, headers, remoteAddress, remotePort, raw`), so returning it whole ships every header incl. `authorization` plus the raw body on every log line in a request context (the `Response:` line from LoggerMiddleware and any service log).
- Nobody reads `req.body` from the logs (grep `req.body|raw.body` in src: only this serializer). caller_attribution (VP-18480) carries the allow-listed claims, so identity is not lost.

## Decisions Made
- Allowlist serializer instead of pino `redact` paths: redact would still ship the body and every other header; allowlist is the smaller surface. Headers kept: host, content-type, content-length, user-agent, x-request-id, x-forwarded-for, origin, referer.
