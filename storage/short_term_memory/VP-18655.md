## Approaches Considered
- Extend `update-clinician` (what Unimod already calls) vs. add a PATCH `update-credentials`
  mirroring `update-opd-time`: chose extend, so the FE ticket needs no new endpoint. The existing
  `if (body.opd_time)` truthiness pattern cannot clear a field, so credentials uses
  `!== undefined` (omitted = unchanged, "" / null = clear).
- Column name `credentials` VARCHAR(50) NULL after `opd_time`; 50 = Unimod limit; prod utf8
  (3-byte) holds `®` fine.
