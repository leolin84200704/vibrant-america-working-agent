## Lessons (flag for dream → ENGINEERING-LESSONS / emr-integration.md)
- **Decode the destination before mirroring it.** A vendor facility code is a *practice* identity. Before copying msh06 from any row,
  (a) list every other row sharing that value, (b) confirm via core that the target provider is a member of the practice those rows
  belong to. The 09-04 audit already had "P00029HUC092017 shared by 18 rows / 15 clinics" one query away and didn't run it.
- **"Restoring" a legacy delivery can restore a legacy misrouting.** 2017-era hard-coded provider→practice mappings (PracticesEnum) do not
  track providers who later leave a practice; a backlog repush multiplies the blast radius (85 reports in 37 minutes).
- **Repush batches to a destination that has not delivered in >90 days need a human re-confirmation of the destination**, not just of the fix.
