## Root cause of the block: the 6-month window is FE-ONLY
- va-portal `src/utils/home/consultWindow.js`: `CONSULT_WINDOW_MONTHS = 6`, `isOutsideConsultWindow(date, format)`.
- Two provider entry points, both gated on the ORDER SERVICE DATE:
  - `src/views/PatientPage/components/PatientTestAction.vue:32` hides the Schedule Consult option when `isOlderThanSixMonths(testDetail.service_date)`.
  - `src/views/home/ScheduleMeeting/related-test-dialog/SearchOrderList.vue:81` disables the row when `isOutsideConsultWindow(order.serviceDate)`.
  - `SearchOrders.vue:454` re-checks on click but uses the **kit received time** (2026-08-26, would have PASSED) — the row is already inert by then, so the received-date path is unreachable.
- LIS-transformer-v2 has **no** date window anywhere: `createEventByPatient`, `isAccessionClaimable`/`AccessionClaimService`, and `validateSlotAvailability` all ignore service date. So NO override/flag/exception mechanism was needed — the backend accepts the booking as-is.
- Answer to AC1: a one-time eligibility override does not exist and is not required; manual booking IS supported, either via `createEventByPatient` (provider-as-patient, what the FE calls) or clinician-side `createEvent` from the clinical team's own calendar UI.

## Lessons Learned
- **"The frontend blocks it" is a hypothesis about where the rule lives, not a finding.** Grepping both sides first (FE constant + BE validator) turned a "can we build an override?" ticket into a "no code needed, the backend already accepts it" ticket. The 4 ACs about override mechanisms were answerable in one grep pass.
- **Two FE gates on the same rule can read different dates.** The click-time check used the kit received date (which would have passed) while the row-level check used the order service date (which fails) — the stricter one runs first, so the lenient path is dead code. When a user says "the UI blocks me", enumerate every gate, not the first one found.
- **Rebuild a blocked user action by replaying the exact FE call chain**, not by writing rows. Zoom link, accession claim, participant rows, confirmation emails and reminder eligibility all came for free and are indistinguishable from a self-service booking.
