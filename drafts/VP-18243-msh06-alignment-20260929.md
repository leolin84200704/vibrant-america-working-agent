## How each row was classified

ChARM's own acknowledgement is the oracle, so most of the table needs no confirmation at all:

- `MSA|AA` -> ChARM accepted the message and echoed the receiving-facility code back. The mapping is proven.
- `MSA|AE ... ChARM ERR:Invalid Receiving Facility ID` -> ChARM rejected it. The mapping is proven wrong.
- no HL7 acknowledgement at all -> not yet provable from our side (either no result has ever been sent
  on that row, or the message was sent with HL7 version 2.3, which ChARM answers with an empty body
  instead of an ACK).
